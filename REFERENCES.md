## Motion and speed pass

The separate awards-web skill was not found in mounted user files, the local skill directories or the cloud catalogue. The user explicitly authorized a GitHub-based fallback. These sources were fetched and inspected:

- [raf-schd scheduling source](https://github.com/alexreardon/raf-schd/blob/master/src/index.js): retain the latest pointer state and batch work into a frame, rather than render on every pointer event. Applied through the scene’s existing frame loop; no package or source copied.
- [Motion render-step source](https://github.com/motiondivision/motion/blob/main/packages/motion-dom/src/frameloop/render-step.ts): reuse frame work and avoid per-frame allocations. Applied through cached pixel sprite canvases, a reused background canvas and bounded effect loops. No code copied. Motion was removed as a runtime dependency because only its reduced-motion hook remained; the native media query now supplies the same preference.
- [Size Limit documentation](https://github.com/ai/size-limit): explicit shipped-resource budgets. Applied as `npm run test:performance`, guarding initial JavaScript and local WOFF2 totals. No dependency added.
- [Animate.css flash source](https://github.com/animate-css/animate.css/blob/main/source/attention_seekers/flash.css): inspected as an attention-effect reference. Repeated flashing was not imported; the title uses one short stepped tune-in and reading content remains stable.

The original effects are intentionally pixel-based: layered rain, small puddle ripples, drifting fog ribbons, eight lamp motes, a restrained ghost wake, a finite banish pulse, five-pixel maximum background pointer movement and brief UI transitions. No scroll hijacking, mandatory custom cursor, remote animation assets or WebGL dependency. All ambient effects stop under reduced motion; the chase remains functional.

## Whole-site pixel world

The current pass extends the pixel aesthetic through the entire document and uses these additional GitHub sources, actually fetched and inspected:

- [98.css native button styling](https://github.com/jdan/98.css/blob/main/style.css), specifically raised/sunken border variables, zero-radius controls, and distinct pressed states. Used to confirm the renderer's existing nearest-neighbour/cached approach while expanding the visual world. No Phaser runtime or copied source was added.

The edge-to-edge city pass keeps these established canvas/pixel-rendering references. New street dressing is original canvas geometry, cached with the existing backdrop. Mouse-following camera drift from the earlier effects pass has been removed; only Pete’s walk moves the scene. No additional external art or code was imported.
